The whole meeting thali.

Recording, transcription, meeting memory, storage hygiene, diagnostics, and agent-safe automation in one local app.

Your meeting notes should have an API.

  • Read sessions, meetings, transcripts, paths, and storage reports as stable JSON.
  • Constrained writes for summaries, meeting metadata, SQLite index updates, and exports.
  • Source evidence stays protected: no agent rewrites of audio, session JSON, or transcript evidence.
$ poha-cli meetings list
$ poha-cli sessions get <session-id> --partial
$ poha-cli diagnostics audio --guided

Local by default.

Poha records and transcribes locally. The standalone app does not configure a remote crash-reporting DSN, and analytics are inactive unless a build explicitly compiles in a valid PostHog key.

Recoverable cleanup.

Storage maintenance validates transcript, audio, chunks, and stems before moving eligible artifacts to macOS Trash. It does not hard-delete meeting evidence.

Build it locally.

Poha currently ships as public source. Build from source to test the macOS app.

$ pnpm install
$ ./script/build_and_run.sh

$ pnpm cargo:check
$ pnpm test:cli
$ pnpm test:transcription
